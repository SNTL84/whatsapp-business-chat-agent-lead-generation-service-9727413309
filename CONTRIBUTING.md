# Contributing to WhatsApp Business Chat Agent

Thank you for your interest in improving this repository!

## Ways to Contribute

1. **Improve Documentation**
   - Better FAQ entries
   - Clearer setup instructions
   - Translations (Gujarati / Hindi / English)

2. **Add Case Studies / Live Demos**
   - Anonymized conversation examples (remove personal numbers & sensitive data)
   - New industry examples (real estate, education, retail, logistics, etc.)

3. **Report Issues**
   - Use the issue templates
   - Describe the problem clearly

4. **Pull Requests**
   - Fork the repo
   - Create a feature branch
   - Make focused changes
   - Open a PR with a clear description
